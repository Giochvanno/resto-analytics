# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.2.0] — 2026-11-25

### Изменено
- В сводке три суммы продаж: **без обслуживания**, **обслуживание 10%** и **с обслуживанием**
  (на странице, в Excel, в API и в CLI). Раньше была одна «Сумма продаж».
- Валовый доход, коэффициент и доля по умолчанию считаются **от продаж без обслуживания**:
  обслуживание — плата за работу зала, а не за блюдо, и на доставке его нет.
- Настоящие скидки (положительная «Сумма скидок» в iiko) больше не путаются с обслуживанием.

### Ломающие изменения
- Настройка `sales_source` заменена на `margin_base` (`without_service` / `with_service`)
  в `config/summary.toml`, в поле формы API и в CLI (`--margin-base` вместо `--sales-source`).
- В ответе API у строк появились `sales_net`, `service`, `sales_total`; `sales` теперь —
  сумма, от которой считается доход. Поле `sales_title` заменено на `margin_base_label`.
- Лист «Сводка» в Excel: столбцы C–I переставлены (см. README).
